        高级设置

        API 地址、工作目录、超时、模型过滤、联网搜索与侧边栏额度卡片等不常修改的选项。

        传输方式

        自动：按套餐判定——Go 订阅账号与 Claude 模型走 /alpha/generate，其余走标准 Provider API；标准接口若返回 403 upgrade_required 也会自动降级并记住该选择。始终 generate：强制走旧传输。始终 provider：强制走标准接口，不做降级。
